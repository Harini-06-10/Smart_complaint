SMART COMPLAINT REGISTRATION SYSTEM v3 - HOW TO RUN
====================================================

YOU NEED: Node.js LTS (https://nodejs.org) and VS Code. MongoDB is NOT required.

EASIEST (Windows): double-click  START-WINDOWS.bat

OR IN VS CODE:
 1. File > Open Folder... > choose THIS folder (the one with package.json in it)
 2. Terminal > New Terminal
 3. Type:   npm run setup      (first time only, needs internet, 2-4 minutes)
 4. Type:   npm run dev
 5. Open Chrome:  http://localhost:5173
